# aQuaDrip v0.2.0 发布说明

## 概述

首个对外发布版本。核心工作流全部可用：**农艺参数驱动设计 → 水力模拟 → 模型校准 → 分区与轮灌 → 结果导出**。基于 QGIS ≥ 3.28 + WNTR，中英双语界面。

## 新增功能

- **项目另存为**：一键复制 GPKG（WAL 安全快照）+ 模拟历史 + QGIS 工程文件到新路径，图层原地重指、下游功能自动切换。
- **多阀一区分区**：现实管网中一个管理分区常由多个阀门同时控制——支持手动自定义标签（任意命名）、按目标流量自动编组（贪心装箱，流量估算优先取最新模拟结果）；轮灌调度按标签分组同开。
- **手动放置毛管**：单击放置单根滴灌带，断续田块按点击位置分段独立放置；自动修正自相交等无效几何田块。
- **节点矢量导出**：可视化结果导出为 GPKG / GeoJSON / Shapefile（node_id / pressure_m / emit_flow / is_emitter）。
- **模拟历史 v2 分片存储**：单条记录一个 gzip 分片 + 轻量索引，add O(1)、列表毫秒级、内存占用降一个量级（1 GB 旧文件迁移后 ~124 MB）。
- **水源连通性诊断**：孤立水源（未接主管）时明确警告并给出距离，避免"模拟全 0"无从排查。
- **水源水头联合校准**：供给受限管网中粗糙率无杠杆时的边界条件校准。

## 修复

- 切割工具三处：经纬度度/米混用、长管（>400 m）上 0.5% 比例阈值吞掉短切除区间、全局捕捉劫持点击导致失手/切错。
- 关闭阀门在 WNTRSimulator 下不关断（忽略阀门 CLOSED 状态）→ 改以闭合短管参与求解。
- 分区下游侧判定不再依赖存储方向（sync 拓扑回写会覆盖方向修正）。
- 含阀门管网模拟结果为空/NaN 的检测与降级重跑；PC/非 PC 滴头混合时 EPANET 全局指数限制的引擎切换。
